# Contributing

Thanks for helping voters get better information. Follow these steps.

1. Open an issue first for anything larger than a typo, so we can agree on the approach.
2. Keep the skill free of personal data and of details specific to one region or election. Use fictional examples ("Springfield County") in tests and docs.
3. Keep the skill neutral across political camps. Every change to the wizard, source lists or fairness checks must work the same for left, center, right and libertarian users.
4. Give every new script `--help`, clear exit codes and one-line status output. Agents read the output, so keep it short.
5. Write in plain language: short sentences, active voice, numbered steps for instructions.
6. Run each changed script's `--help` and a small smoke test before you open a pull request.

## Wanted

- Helpers for state campaign-finance portals (one small script per state)
- Scripts and setup notes for Windows and Linux
- Translations of the page template
- Test ballots from other states, with what the skill got right and wrong
- Reports of wrong facts (use the "Wrong fact" issue template)
