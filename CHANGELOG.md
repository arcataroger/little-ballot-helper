## v0.1.0 (2026-10-19)

First release.

- Nine-phase workflow: environment check, values wizard, official ballot lock, source map, symmetric evidence ledgers, ranking with forks and a sensitivity check, fact-check and blinded swap test, page build, refresh.
- Scripts: setup_macos.sh, forum_transcripts.sh, captions.py, transcribe, fec.py, sensitivity.py, swap.py, linkify.py, check_links.py.
- Page template with forks, presets, measure and multi-seat cards, dark mode, print layout and screen-reader stance labels.
- Tested end to end on one county general-election ballot in a clean-context trial.
